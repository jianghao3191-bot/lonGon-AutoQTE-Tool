lonGon-AutoQTE-Tool  v1.0.0        made by lonGon

===========================================================
这是什么
===========================================================
我给自己做的单机游戏写的一个自动 QTE 小工具。
它只做三件事：截屏幕中心一小块 -> 认出白色完美区和转动的指针 -> 到点按你设的键。
不读内存、不注入进程、不联网、没有卡密、没有时间戳校验。

===========================================================
第一次使用（3 分钟）
===========================================================
1. 双击 lonGon-AutoQTE-Tool.exe
2. 把游戏切到前台，让 QTE 停在屏幕上别动
3. 点"参数设置 -> 目标窗口 -> 取前台"，把目标锁成你的游戏窗口
4. 先勾上"只识别不按键"，看左边"检测画面"：
     - 绿色弧      = 识别到的白色完美区（应该正好盖住白条）
     - 白线 + 白点 = 识别到的指针方向
     - 绿色小圆圈  = 预测落点（应该在白区中间）
   对不上就看下面"识别不对怎么办"
5. 确认没问题，取消"只识别不按键"，点右上"启动"（或按 F8）
6. 打不中完美就微调"提前量"（0.5ms 一步）
7. 参数调乱了，点"参数设置"右上角"恢复默认"一键还原

快捷键： F8 启动/停止      F9 紧急停止

小提示：数值框要先点一下（拿到焦点），滚轮才会改数字；
平时滚轮划过只会滚动页面，不会误改参数。

===========================================================
识别不对怎么办
===========================================================
- 白条盖不全 -> 调低"白阈值"（205 往下试）
- 把别的白东西认成白区 -> 调高"白阈值"，或把"白区确认"从 5 调到 7
- 指针方向不准 -> "指针来源"换成"只用运动"；或把"判定环 内"从 0.55 调到 0.7
- 干脆看不到画面 -> "截图方式"换"GDI 兼容模式"；独占全屏可以试"窗口 / OBS 投影"

===========================================================
打太早 / 打太晚
===========================================================
只调"提前量"：
  落在白区前半段 = 早 = 调大（6.0 -> 6.5 -> 7.0 ...）
  落在白区后半段 = 晚 = 调小（6.0 -> 5.5 -> 5.0 ...）
每次 0.5ms，调两次基本就准了。

===========================================================
别的
===========================================================
- 配置存在 exe 旁边（lonGon-AutoQTE-Tool.json），删掉就恢复默认
- 全程不往 C 盘写东西；截图只在内存里，不落盘
- 想看自己机器的实际性能：看"推理"面板右下角的"截图耗时 + 推理耗时"
  两个加起来 <= 4ms 就是绿的，说明没拖后腿
- OBS：点"纯净窗口"会弹一个无边框置顶小窗，OBS 加"窗口采集"选它就行

===========================================================
注意
===========================================================
本工具只用于 lonGon 自己的单机游戏。
不要在带反作弊的联机游戏里使用，也不要拿它去对抗反作弊——
那不属于这个工具支持的场景。
